# نظام سريع وبنشر PRO - Quick Lube & Tire Touch POS (Yemen)
### النظام الإداري والمحاسبي المتكامل لمراكز تغيير الزيوت والبناشر وخدمات الإطارات والبطاريات بالسوق اليمني

نظام محاسبي وميداني محلي فائق السرعة مبني بهندسة برمجية نظيفة وقابلة للتوسع (Clean & Modular Offline-First Architecture)، مخصص لمحطات ومراكز غيار الزيوت والسيفونات، والبناشر، وتغيير الإطارات والبطاريات في السوق اليمني. مصمم وفق أحدث معايير Apple (iPadOS & macOS Glassmorphism) ومتوافق 100% مع شاشات اللمس (Touch Screen POS) وكافة درجات دقة الشاشات (Responsive Smooth Scrolling).

---

## 🚀 طريقة التشغيل المباشرة (بنقرة واحدة على ويندوز)

تم إعداد ملفات تشغيل وتنفيذ وإيقاف مباشرة في المجلد الرئيسي للمشروع:

### 1. تشغيل النظام:
انقر نقراً مزدوجاً على:
```cmd
تشغيل_النظام.bat
```
أو
```cmd
start.bat
```
يقوم السكريبت تلقائياً بالآتي:
- تشغيل خادم النظام وقاعدة البيانات المحلية على المنفذ `http://localhost:5000`.
- تشغيل واجهة نقطة البيع اللمسية على المنفذ `http://localhost:3000`.
- فتح النظام تلقائياً في **نافذة تطبيق مستقلة بدون أشرطة تصفح (Kiosk / Desktop App Mode)** عبر Microsoft Edge أو Google Chrome لتجربة تشغيلية مثالية كبرنامج مثبت على الكمبيوتر.

### 2. إيقاف النظام بأمان:
انقر نقراً مزدوجاً على:
```cmd
ايقاف_النظام.bat
```
أو
```cmd
stop.bat
```
يقوم بإغلاق العمليات والخوادم بأمان والحفاظ على سلامة قاعدة البيانات.

### 3. التشغيل اليدوي عبر موجه الأوامر (Terminal):
```bash
# تشغيل الخادم الخلفي (Backend)
cd server
node index.js

# تشغيل الواجهة اللمسية (Frontend) في نافذة أخرى
cd client
npm run dev
```

## 📖 دليل التشغيل السريع الميداني (F1 In-App Guide)
يمكنك في أي وقت وأنت داخل النظام الضغط على مفتاح **`F1`** من لوحة المفاتيح أو النقر على **"دليل التشغيل الشامل 📖"** أسفل القائمة الجانبية لفتح دليل الاستخدام التفاعلي الذي يشرح:
1. دورة عمل كاشير نقطة البيع السريعة وكرت الخدمة الرقمي.
2. إدارة المخزون وتحويل العبوات وحساب التكلفة الفعلية.
3. إدارة الصندوق النقدي (1101) وسندات القبض والصرف ومسحوبات المالك (3101).
4. إغلاق الوردية والتقرير التنفيذي وخريطة ساعات الذروة.
5. الأمان وسلامة البيانات والنسخ الاحتياطي التلقائي اليومي.

## 🌟 الهيكلية الوظيفية للمشروع (المراحل 1 - 6 والترقيات الاحترافية)

### 1. شاشة نقطة البيع اللمسية السريعة (Touch POS UX)
* **البحث الفوري المتعدد**: استدعاء بيانات السيارة برقم اللوحة (خصوصي/نقل/أجرة)، رقم الجوال، أو اسم العميل.
* **شريط نماذج العرض التسويقي السريع (Quick Demo Chips)**: بطاقات لاختيار فوري لأشهر 4 سيارات يمنية مسجلة لتوضيح سرعة البرنامج.
* **تكرار آخر خدمة بنقرة واحدة (1-Click Repeat Service)**: نسخ زيوت وفلاتر الزيارة السابقة للسلة بنقرة واحدة لتوفير وقت العميل.
* **عداد المسافات وموعد التغيير القادم**: ضبط افتراضي 3,000 كم متوافق مع بيئة اليمن وظروف الطرق، مع حرية التعديل لـ 5,000 أو 7,000 أو 10,000 كم أو كتابة العداد يدوياً.
* **فحص السلامة المجاني لـ 8 نقاط (8-Point Touch Safety Inspection)**: فحص ماء الرديتر، زيت الفرامل، المساحات، ضغط الإطارات، الفلاتر، التهريب، والبطارية، تظهر في الفاتورة وبطاقة الواتساب.
* **بوابة الدفع المتعددة للسوق اليمني**: كاش 💵، محفظة جيب 📱، محفظة جوالي 📱، بنك الكريمي 🏦، والبيع الآجل/الجزئي 📝.
* **تمرير وسلاسة فائقة**: تصميم متجاوب يسمح بالتمرير العمودي السلس لكافة عناصر الشاشة وعربة الفاتورة دون أي قص للبيانات أو أزرار الحفظ.

### 2. المخزون المتخصص وتحويل العبوات والباركود
* **كتالوج الزيوت الشامل**: مصفوفة اللزوجات، تصنيفات البنزين والديزل، مواصفات API (SP/SN/CK-4).
* **تحويل العبوات والتجزئة**: بيع بالبرميل واللتر، أو الكرتون والعلبة، مع احتساب التكلفة تلقائياً.
* **كود الإطارات (DOT Code)**: رصد أسبوع وسنة الإنتاج وحساب العمر الزمني للإطار وتنبيه العميل.
* **طباعة استيكرات الباركود الحرارية**: توليد وملصقات باركود قياسية للرفوف والعلب.
* **كشف مقترحات أوامر الشراء (Reorder PO Sheet)**: استخراج ملف طباعة بمطالبات التوريد ومراسلة الموردين.

### 3. المشتريات وتوزيع تكلفة الشحن (Landed Cost Engine)
* **توزيع أجور النقل والشحن**: توزيع تكاليف الشحن الداخلي على أصناف الفاتورة تلقائياً لتحديث سعر التكلفة الفعلي.
* **أرشيف ومطابقة فواتير الموردين**: إضافة رقم الفاتورة الدفترية للمورد وتتبع أعمار الذمم وجدول الاستحقاقات القادمة.
* **مرتجعات المشتريات وسندات الصرف**: تسجيل المرتجع مع قيود يومية عكسية تؤثر على المخزن وحساب المورد.

### 4. الخزينة والمحاسبة وسندات القبض (Financial Vault & Accounting Hub)
* **شجرة حسابات مبسطة ومطابقة للمعايير**:
  - `1101` الصندوق النقدي الحي (الدرج).
  - `1102` أرصدة المحافظ والبنوك (كريمي، جيب، جوالي).
  - `1201` ذمم ومدينو العملاء.
  - `2101` ذمم ودائنو الموردين.
  - `3101` مسحوبات المالك الشخصية.
  - `4101` إيرادات مبيعات الزيوت والقطع.
  - `4102` إيرادات خدمات الورشة والبنشر.
  - `5101` تكلفة البضاعة المباعة (COGS).
  - `5201` المصروفات التشغيلية.
* **دفتر القيود اليومية التلقائي (Double-Entry General Ledger)**: ترحيل آلي متوازن لكل معاملة بدون تدخل يدوي.
* **مطابقة وجرد الصندوق الفعلي**: مقارنة النقدية الفعلية بالرصيد الدفتري المسجل واكتشاف الفروقات.
* **كشف حساب شامل ومفصل (Statement of Account)**: كشف تفصيلي لحساب أي عميل أو مورد أو عامل مع زر طباعة ومشاركة واتساب مباشرة.

### 5. إدارة الفنيين والعمال والمسحوبات اليومية
* متابعة إنجاز كل فني يومياً وعدد السيارات والخدمات المنفذة.
* توثيق السلف والمسحوبات اليومية واحتساب الصافي المستحق وتوليد سند صرف رسمي.

### 6. تقرير الإغلاق المالي اليومي وساعات الذروة
* **تقرير إغلاق اليومية والوردية**: ملخص تنفيذي يجمع المبيعات، المقبوضات، المصاريف، المسحوبات، وأرصدة الصندوق.
* **خريطة ساعات الذروة (Peak Hours Heatmap)**: تحليل بياني لتوزيع دخول السيارات على مدار ساعات اليوم لتنظيم مناوبات العمال وتخفيف الازدحام.
* **نظام الورديات الاختياري**: يمكن تفعيله أو إلغاؤه من الإعدادات بمرونة تامة.
* **إرسال ملخص واتساب بنقرة واحدة**: صياغة رسالة رسمية أنيقة لمالك المركز ترسل مباشرة عبر واتساب.

### 7. رادار المتابعة الاستباقية وأساطيل الشركات
* رصد السيارات التي اقترب موعد غيار زيتها (على أساس 3,000 كم).
* إرسال تذكيرات لطيفة بالواتساب مع توثيق حالة وتاريخ الإرسال.
* دعم حسابات أساطيل الشركات وتحديد نسب خصومات خاصة تطبق تلقائياً في شاشة الـ POS.

### 8. محرك الأمان والنسخ الاحتياطي التلقائي (Auto-Backup & Disaster Recovery)
* **نسخ احتياطي يومي آلي**: عند بدء تشغيل الخادم يتم أخذ نسخة كاملة من قاعدة البيانات وتخزينها في المجلد `server/backups/quick_lube_backup_YYYY-MM-DD.sqlite`.
* **سياسة الحفظ والتدوير (Retention Pruning)**: الاحتفاظ بآخر 30 يوماً وحذف النسخ الأقدم تلقائياً لمنع استهلاك مساحة القرص.
* **فحص سلامة قاعدة البيانات (`PRAGMA integrity_check & optimize`)**: فحص تلقائي لضمان عدم وجود أي تلف أو تعارض في البيانات المحلية.
* **إنشاء نسخة احتياطية فورية يدوياً**: بضغطة زر من تبويب الأمان في دليل التشغيل أو عبر الـ API.

## 🛠️ البنية التقنية (Tech Stack)
* **Backend**: Node.js, Express, `better-sqlite3` (WAL Mode & Foreign Keys ON).
* **Frontend**: React 19, Vite, Tailwind CSS v4, Lucide Icons.
* **Database**: SQLite3 (`server/db/quick_lube.db`) مع محرك نسخ يومي في (`server/backups/`).
* **Environment**: محلي 100% بدون إنترنت (Offline-First / Zero Latency).
